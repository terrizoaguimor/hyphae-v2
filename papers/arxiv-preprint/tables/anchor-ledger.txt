# Append-only anchor ledger — ADR-0033
# Real hyphae_storage::Journal: 8 appends, head anchored to an
# append-only Ed25519 ledger after each (epochs 0..7). The ledger
# is itself hash-chained. Key held outside the store.

## 1. Freshness — rollback to epoch 3 + replay its genuine anchor
single-head anchor (ADR-0032)      ACCEPTS (no detection)
append-only ledger (ADR-0033)      REJECTS (DETECTED)
#   The stale anchor is a REAL signature over the rolled-back head,
#   so the single-head check accepts it (freshness gap). The ledger
#   rejects it: head@epoch3 is not the ledger tail (epoch 7).

## 2. Non-equivocation — two histories diverging at epoch 3
forked view verifies on its own    YES
cross-view consistency check       REJECTS (DETECTED)
#   Each view is internally valid, but comparing them (an auditor
#   holding one, gossip/witness offering the other) detects the
#   divergence: equivocation caught.

## 3. Ledger tamper-evidence — forge a published entry's head
tampered ledger verifies           REJECTS (DETECTED)
#   The signature at that epoch no longer covers the forged head;
#   verify_ledger rejects the published log.

## 4. Withholding — store presents a truncated ledger as the latest
freshness alone (ledger only)      ACCEPTS (no detection)
ledger + external witness          REJECTS (DETECTED)
#   The truncated ledger is internally valid and its tail matches
#   the rolled-back head, so freshness accepts it. The witness saw
#   epoch 7 — the withheld ledger never reaches it, so the combined
#   check rejects it. Withholding caught.

# Summary:
#   threat                         single-head   ledger    ledger+witness
#   chain-aware head rewrite         DETECTED     DETECTED     DETECTED
#   rollback + stale-anchor replay   MISSED       DETECTED     DETECTED
#   equivocation across views        n/a          DETECTED     DETECTED
#   forged published anchor          n/a          DETECTED     DETECTED
#   withholding (truncated ledger)   n/a          MISSED       DETECTED
#
# ADR-0033 (ledger) closes freshness + non-equivocation; ADR-0034
# (witness) closes withholding by pinning the ledger tail to an
# INDEPENDENT observer. In deployment the witness is a timestamp
# authority / transparency witness / OpenTimestamps commitment.
# Remaining: anchor-key rotation, and the source-ingestion trust
# boundary (who attests fragments were ingested faithfully).

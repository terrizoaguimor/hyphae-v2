# Reading:
#  * verbatim-journal & merkle-log share the SAME detection profile —
#    store-only detected + localised; chain-aware defeats the bare
#    check but the external anchor catches it; head_rollback is
#    consistent-by-construction (anchor catches via head mismatch).
#    Detection is a property of the append-only-log CLASS, not of the
#    flat chain. They differ on PROOF COST: flat chain O(n) vs Merkle
#    O(log n) inclusion proofs (table above).
#  * signed-entries (no chain) → catches in-place edits and forged
#    inserts via per-entry signatures, but MISSES delete, reorder,
#    replay (duplicate) and rollback: signing is not chaining. No
#    head, so no anchored detection and no membership proof.
#  * echo-no-journal → 0% everywhere: no journal, no provenance.
#  * chain-aware+key → anchor key compromised → no protection. The
#    guarantee's boundary: holds against any attacker who does NOT
#    hold the anchor signing key.
#  Hyphae and echo+journal share the verbatim-journal row; the
#  provenance property is the addable layer, not the realizer.

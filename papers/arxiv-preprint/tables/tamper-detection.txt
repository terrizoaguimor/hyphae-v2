# Minimal provenance benchmark
# Real hyphae_storage::Journal hash chain over raw fragment bodies.
# The journal layer is realizer-independent: this measures the
# (verbatim + hash-chain) provenance layer shared by Hyphae AND an
# echo+journal baseline. N = 10 fragments.

## Adversary A: store-only (write access, no chain logic)
mode         detected     localised seq 
----------------------------------------
edit         YES          4             
delete       YES          4             
insert       YES          10            
reorder      YES          4             

## Adversary B: chain-aware (recomputes chain forward + rewrites head)
verification           detected                   localised seq 
------------------------------------------------------------
bare chain (verify)    NO (defeats bare chain)    -             
anchored head (Ed25519) YES (anchor catches it)    n/a           
#   (bare-chain verify still passes after the chain-aware attack: true; 
#    the anchored signature over the original head fails against the rewritten head.)

# Detection matrix (post-ingest store tampering):
#
#   System                       store-only  chain-aware   chain-aware
#                                    adv          adv        + anchor
#   Verbatim + journal            100% (all)   defeated      DETECTED
#     (Hyphae AND echo+journal)   + localised  (bare chain)  (Ed25519 head)
#   Echo (no journal)               0%           0%            n/a
#   LLM-RAG (no journal,            0%           0%            n/a
#     paraphrases; not byte-bindable for post-hoc audit either)
#
# Reading: the (verbatim + hash-chain journal) layer detects and
# localises every store-only tampering mode, realizer-independently
# (Hyphae and echo+journal share it identically). A chain-aware
# adversary defeats the BARE chain by rewriting the head -- but an
# externally anchored head (Ed25519-signed by a key the store does
# not hold) catches even that attack, because the attacker cannot
# re-sign the rewritten head. This closes the load-bearing
# dependency: tamper-evidence now holds against any attacker who
# does not hold the anchor signing key. The contribution is the
# addable provenance layer, not the realizer.

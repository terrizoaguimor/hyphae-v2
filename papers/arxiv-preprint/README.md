# arXiv preprint — Hyphae v0.1

LaTeX source for the v0.1 arXiv preprint.

## Title

> **Architectural Verbatim Quotation: Matching Frontier LLMs at ~10⁶ Lower Latency**

```
arxiv-preprint/

├── references.bib          # BibTeX bibliography
├── sections/

│   ├── 02-related-work.tex
│   ├── 03-architecture.tex
```

Roughly **10-12 pages** in NeurIPS-similar formatting (article class, 11pt,
1in margins). Plus appendix.

## Compile

Requires a LaTeX distribution (`pdflatex` + `bibtex`). On macOS:

```bash
brew install --cask mactex-no-gui   # ~1.5GB, no GUI
# or: brew install --cask basictex   # ~100MB, install needed packages on demand
```

Then:

```bash
cd papers/arxiv-preprint
pdflatex main && bibtex main && pdflatex main && pdflatex main
# Produces main.pdf
```

## Regenerate figures

The Pareto plot is rebuilt from the JSON envelopes in
`../../bench/baseline-llm-rag/results/`:

```bash
cd ../../bench/baseline-llm-rag
uv run python ../../papers/arxiv-preprint/scripts/make_pareto_plot.py
```

This requires `matplotlib` (already in the bench's uv env).

## arXiv submission

arXiv compiles from source. To submit:

1. Build locally first to verify it compiles clean.
2. Tarball the directory: `tar czf hyphae-v01-arxiv.tar.gz main.tex sections/ references.bib figures/`
3. Upload at <https://arxiv.org/submit>.
4. Category: `cs.CL` (Computation and Language) primary, `cs.AI` cross-list.
